Selected Work

01

2026 · Backend & API · Team of 4 · UTH × VNPT NET

Network Quality Map

A web map that shows 4G mobile network quality by region, built during the UTH × VNPT NET enterprise semester. KPIs are computed per cell and rolled up to provinces and wards with traffic-weighted averages.

  • Built the FastAPI backend on PostgreSQL 17 with PostGIS, and wrote the API contract for the map frontend.
  • Covers 34 provinces and 168 wards of Ho Chi Minh City, hourly over 30 days, on clearly labelled simulated data.
  • Only aggregated figures are exposed; no station coordinates or subscriber data.
  • FastAPI
  • PostgreSQL
  • PostGIS
  • Python
